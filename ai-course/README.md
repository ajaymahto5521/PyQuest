# AI Engineer Foundations Quest 🐍

A free, gamified 56-day course covering the foundations every AI engineer needs:
Python, the command line, Git, Docker, SQL, APIs, NumPy, pandas, and the math
behind machine learning. One hour a day.

## Features
- 56 daily plans split into timed steps, with a built-in focus timer
- Study notes for every day, with code examples
- 840 multiple-choice questions (easy, medium and hard for each day) with explanations
- 112 "explain it" questions with model answers
- XP, levels, streaks, badges and boss-day projects
- Progress saved in the learner's own browser; no account needed

## Run it locally
Open `index.html` in any modern browser. That's it.

## Deploy free on GitHub Pages
1. Create a new public repository on GitHub and upload these files.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then save.
4. After a minute your site is live at `https://<your-username>.github.io/<repo-name>/`.

## Contributing
Found a mistake in a question or have a better explanation? Open an issue or a pull request.
Course content lives in the `C[...]` objects inside `index.html` (notes, MCQs and descriptive questions per day).
